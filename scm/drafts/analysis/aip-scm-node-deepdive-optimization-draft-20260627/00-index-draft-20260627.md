# 供应链 AIP 数据治理工作台 — 节点深度优化方案（总纲索引）

## 0. 这是什么

一套针对 `scm-data-governance-workbench-v0` 原型的**深度优化方案集**，回应需求："借用 AIP（Palantir）方法论，把供应链数据治理工作台做得更完善、更自动化、能产出业务价值。" 聚焦用户点名的 5 个侧边导航节点——**标签工程 · 指标工程 · 指标体系 · 洞察故事线 · Palantir 核心要义**——逐个做 MECE 深度拆解，并以工程债务审计打底、以交叉审计收口。

**两条硬约束**（全系列贯彻）：① **不改动任何现有代码**，只产出优化设计与落地计划；② 继承平台受控边界 `productionWrites=false / providerCalls=false / erpWriteback=false`，动作止于 `suggestion_review_replay`。

## 3. 全系列术语与枚举权威表（单一真源）

> 各篇引用本表，不另行定义（消解交叉审计 X-01/X-02/X-03、待办 C-01）。

| 概念 | 标准定义 / 枚举 |
|---|---|
| evidence_level | `seed`（种子，含 prototype_seed）/ `real`（真实未认证）/ `certified`（认证）|
| 指标认证 | 三签 `owner_sign + lineage_sign + quality_sign` → certified（03）|
| 标签生命周期 | `draft → reviewed → active → deprecated → archived`（02）|
| 维度兼容 | `confirmed / candidate / forbidden`（03）|
| 树关系类型 | `CONTAINS / DECOMPOSED_TO / DRIVES / CORRELATES`（04）|
| "权重"口径 | 指标**内**权重=03 组合公式系数；指标**间**权重=04 树边权重；同值时 04 引用 03 |
| 动作分级 | 只读证据 → 受治理建议 → 审批任务 → 受控导出 → API 写回 → 策略自动化（06）|
| 优先级 | P0 可信/安全红线 · P1 闭环规模化 · P2 可维护性 |
| 受控边界 | productionWrites / providerCalls / erpWriteback 全 false；动作止于 suggestion_review_replay |

## 4. 关键路径总览（落地顺序）

```text
W1  还可信债：移密钥(D-P0-01) + 标注种子(F) + 定术语表
W1-2 03-P0：Top-12 指标坐实血缘 + 三签认证   ← 总瓶颈，解锁全链
W2  02-P0 标签坐实  ∥  04-P0 体系回填权重+MECE 校验
W3  05-P0 履约页 SCQA 故事骨架  +  06-P0 跑通 3 端到端闭环+灌轨迹
W4  设计冻结：数据模型增量评审 + 巨石拆分/RBAC 模型
```

硬约束：**03-P0 → (02-P0 ∥ 04-P0) → 05-P0 → 06-P0**。详见 07 第 3、7 节。
