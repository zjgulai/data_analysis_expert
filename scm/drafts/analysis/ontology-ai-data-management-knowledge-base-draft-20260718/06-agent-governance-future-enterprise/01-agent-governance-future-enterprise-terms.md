# 第 9–10 章新增治理与未来企业术语

仅收录相对 M2-D 新增的来源派生术语。

| 首选词 | 检索别名 | 来源内定义 | 不等同于 | 来源小节 |
|---|---|---|---|---|
| 碳硅协同治理 | 碳基人与硅基 Agent 协同治理 | 围绕人员与 Agent 的目标、权限、行为、证据和责任设计的协同治理概念。 | 纯技术访问控制 | 9.1.1、9.1.2、9.1.3、9.1.4 |
| 六类证明体系 | Agent 六类证明 | 由身份、资产、授权、合约、追溯和贡献证明组成的作者可信协作框架。 | 已认证行业标准 | 9.2.1、9.2.2、9.2.3、9.2.4、9.2.5、9.2.6 |
| 碳硅混合 DID | 碳硅混合身份档案链 | 为人员与 Agent 提供统一可验证标识并关联动态身份属性的作者候选模式。 | 企业账号 | 9.2.1 |
| 数字资产产权链 | 数字资产来源链 | 用哈希、权属凭证和变更记录关联模型、数据、模板等数字资产来源与流转的候选结构。 | 法律产权登记 | 9.2.2 |
| 权限凭证链 | 可验证权限凭证 | 显式携带授权主体、范围、条件、时效与撤销状态的动态权限证明机制。 | 永久角色权限 | 9.2.3 |
| 智能合约协作流水线 | 合约证明 | 把跨主体业务条件编码为可自动校验和推进节点的协作执行模式。 | 普通工作流脚本 | 9.2.4 |
| 操作哈希链 | 全链路操作哈希链 | 将主体、操作、时间和前序哈希串联，用于完整性验证与行为回放的记录链。 | 源事件真实性证明 | 9.2.5 |
| 贡献证明 | 贡献值计量链 | 按显式维度和权重记录人员与 Agent 贡献并用于候选价值分配的作者机制。 | 客观公平评价 | 9.2.6 |
| 三支柱 Agent 治理 | 本体约束+AI 智能+人类监督 | 由本体边界、AI 自主能力和人类价值监督共同组成的分层治理框架。 | 完全自治 | 9.3.1 |
| 本体动态治理 | 动态本体治理 | 持续感知业务变化、校准本体、调整 Agent 行为并反馈验证的治理过程。 | 定期版本发布 | 9.3.2 |
| 连接强度 | 动态契合度 | 作者用于描述业务、本体和 AI 之间变化传导速度、准确性与双向影响程度的概念。 | 神经网络权重指标 | 9.3.2 |
| 多模态本体 | 多模态本体建模 | 把文本、图像、语音、视频和传感器信号统一映射到业务概念与关系的本体形态。 | 多模态向量库 | 9.3.3 |
| AI 本体建模师 | 大模型本体建模师 | 由大模型承担候选知识提取、结构生成、逻辑检查和交互修正的作者未来角色。 | 无需人工审核的建模器 | 9.3.4 |
| 人机共享记忆 | 本体共享记忆 | 以受控本体承载组织规则与经验，使人员更新意图、Agent 读取并反馈实践的共同记忆机制。 | 模型参数记忆 | 9.3.5 |
| 三重世界模型 | 物理逻辑智能三重世界 | 以物理世界、逻辑世界和智能世界共同描述企业数字孪生的作者战略框架。 | 单一数字孪生平台 | 10.1.1 |
| 世界模型 | 现实引擎；因果镜像 | 对物理状态、客观规律、动态演化与行动结果进行建模和推演的模型。 | 业务本体模型 | 10.1.1、10.1.2、10.1.3 |
| 物理—逻辑双重学习 | AI 双重学习 | AI 同时学习物理因果规律和业务语义规则，并在价值治理下协同更新的作者范式。 | 双模型集成 | 10.1.2 |
| 智能原生企业 | 认知驱动企业 | 把本体与 Agent 作为业务底层能力，使智慧资产、流程和组织持续进化的作者未来企业形态。 | 部署聊天机器人的企业 | 10.2.1 |
| 说服边界 | AI 语言边界 | 规定 Agent 可主动发起的话题、可暗示的结论、影响对象和透明义务的人机交互治理边界。 | 操作权限 | 10.2.3 |
| 本体分身治理 | Agent 分身治理 | 按共享本体版本、能力和权限管理大量 Agent 分身，并控制学习同步与全息审计的作者 IT 治理概念。 | 逐账号配置 | 10.2.3 |
| 知识数据流程 IT 四维融合 | 四维融合 | 在业务本体层统一知识连接、数据关系、流程边界和 IT 分身治理的作者管理框架。 | 技术系统集成 | 10.2.3 |
