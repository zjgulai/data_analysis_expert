# 本体约束、候选可信底座与分层治理框架

## 核心结论

作者以业务本体划定 Agent 语义和行动边界，以区块链候选能力记录身份、授权与行为，再按场景风险调节自主、约束和监督强度。

## 关键要素

- 治理对象是 Agent 及其跨系统协同。
- 本体提供任务、规则、权限和资源边界。
- 区块链被设想为可信记录层。
- 高风险强化控制，确定性场景释放自治。

## 适用场景

- 设计企业 Agent 治理分层
- 区分语义约束与行为审计职责

## 不适用边界

- 区块链不是所有审计场景的必选技术。
- 来源没有给出生产架构、容量或合规验证。
