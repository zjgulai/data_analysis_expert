# 身份、资产、授权、合约、追溯、贡献六类证明

## 核心结论

作者以六类证明覆盖 Agent 是谁、拥有什么、能做什么、按何规则执行、如何追溯及如何计量贡献，试图形成碳硅协作的权责与审计框架。

## 关键要素

- 身份与资产证明建立主体和权属。
- 授权与合约证明控制边界和执行。
- 追溯证明保留操作链。
- 贡献证明支持价值计量。

## 适用场景

- 梳理 Agent 权责证据需求
- 设计跨主体可信协作概念模型

## 不适用边界

- 六类证明是作者框架，不等于已验证标准。
- 采用区块链前仍需比较数据库、签名日志和审计平台。
