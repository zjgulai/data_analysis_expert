# 角色、协作、层级、考核驱动的 Agent 组织网络

## 核心结论

作者让业务人员成为本体定义者和 Agent 监督者，并像设计团队一样定义 Agent 角色、协作协议、层级委派和多维考核，进一步探索 Agent 中心组织。

## 关键要素

- Agent 角色有清晰职责和目标。
- 统一语义支持协商和任务委派。
- 考核覆盖质量、时效、资源和贡献。
- 人类负责目标、边界、例外和复盘。

## 适用场景

- 设计多 Agent 组织拓扑
- 建立人机混合责任与评价框架

## 不适用边界

- Agent 中心组织是作者设想而非成熟范式。
- 绩效指标必须防止奖励黑客和责任稀释。
