# 碳硅混合身份与数字资产来源链

## 核心结论

作者用 DID 和可验证凭证统一人员与 Agent 身份，并用哈希指纹及产权凭证关联模型、数据、模板的权属与变更轨迹。

## 关键要素

- 人员与 Agent 都有可验证标识。
- 动态属性反映任职、资质和能力。
- 资产哈希支持变更检测。
- 权属和授权规则与资产凭证关联。

## 适用场景

- 多主体身份互认设计
- 模型与知识资产来源追踪

## 不适用边界

- 身份互认需要可信签发者和撤销机制。
- NFT 式凭证不当然产生法律产权。
