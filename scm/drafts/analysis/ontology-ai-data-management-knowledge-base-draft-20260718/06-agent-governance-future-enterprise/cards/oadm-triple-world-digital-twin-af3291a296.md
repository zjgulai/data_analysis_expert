# 物理、逻辑、智能三重世界的企业数字孪生

## 核心结论

作者以世界模型表达现实规律、本体模型表达业务知识、AI 与 Agent 承担智能推演和执行，三者共同构成服务实体业务的企业数字孪生。

## 关键要素

- 物理世界提供状态与因果。
- 逻辑世界提供知识与规则。
- 智能世界负责感知、推演和行动。
- 社会伦理与实体价值是上层边界。

## 适用场景

- 规划企业统一认知架构
- 区分世界模型与本体模型职责

## 不适用边界

- 数字孪生是现实的有损抽象。
- 不得用纯数字指标替代人本、伦理与实体交付。
