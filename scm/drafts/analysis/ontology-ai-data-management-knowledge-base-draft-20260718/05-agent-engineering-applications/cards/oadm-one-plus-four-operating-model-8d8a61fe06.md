# 总体组加四专业小队的 1+4 协同模式

## 核心结论

作者以总体组统筹节奏、价值和复制，由本体认知、数据眼睛、Agent 大脑和行动手脚四队分别负责知识、感知、决策和执行。

## 关键要素

- 总体组负责立项、评审和推广。
- 本体队沉淀专家规则。
- 数据与 Agent 队连接事实和决策。
- 行动队把指令封装成受控接口。

## 适用场景

- 组织端到端 AI 场景攻坚
- 明确跨职能交付责任

## 不适用边界

- 1+4 是作者组织建议，不等同于既有项目组织。
- 真实执行接口仍需安全审批和运维责任。
