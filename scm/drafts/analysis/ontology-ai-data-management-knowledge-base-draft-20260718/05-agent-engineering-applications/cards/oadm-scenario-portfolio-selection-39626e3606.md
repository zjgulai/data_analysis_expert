# 以痛点、价值和结构化适配度选择场景

## 核心结论

作者以拉齐能力、动态响应和智能资源供给为价值主张，优先语义复杂、规则明确、高合规且能产生净收益的场景，排除变化过快、规则模糊或低价值任务。

## 关键要素

- 先验证是否解决真实业务痛点。
- 五类痛点覆盖数据、语义、人力、经验和安全。
- 适合场景需能形式化规则和审计。
- 本体成本不得超过预期收益。

## 适用场景

- 建立本体加 AI 场景漏斗
- 制定试点排除条件

## 不适用边界

- 三大价值和五类痛点是作者框架。
- 投入产出需用项目数据量化。
