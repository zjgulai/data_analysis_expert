# 第 7–8 章新增 Agent 与应用术语

仅收录相对 M2-C 新增的来源派生术语。

| 首选词 | 检索别名 | 来源内定义 | 不等同于 | 来源小节 |
|---|---|---|---|---|
| 意图与本体对齐 | 意图本体映射 | 将 Agent 任务语义与本体中相关概念、规则和知识边界建立映射的调用前置过程。 | 本体检索 | 7.1.2 |
| 最小必要本体 | 最小本体片段 | 仅包含当前任务决策必需概念、关系、规则与约束的按需加载本体子集。 | 完整本体库 | 7.1.3 |
| 图向量库检索 | 本体向量检索 | 将本体节点或子图编码为向量并按语义相似度召回候选知识的检索方式。 | 图数据库精确查询 | 7.1.3 |
| 记忆增强调用 | 本体记忆调用 | 结合 Agent 短期上下文与长期成功模式动态筛选本体片段的调用方式。 | 静态映射 | 7.1.3 |
| 本体 Skill | 本体技能封装 | 包含功能、输入输出和本体逻辑，可被 Agent 规划与渐进调用的模块化知识单元。 | 普通提示词 | 7.1.3 |
| 本体嵌入 | 本体模型嵌入 | 将符号化本体逻辑转译为模型可理解和遵循的业务上下文或训练信号。 | 向量嵌入 | 7.1.4 |
| 本体约束强度 | 规则约束等级 | 按场景风险配置规则对 Agent 推理自主空间限制程度的强、中、弱等级概念。 | 模型置信度 | 7.2.2 |
| 执行事件总线 | 多 Agent 执行总线 | 由本体定义任务、状态和异常语义，用于主子 Agent 传递指令与反馈的交互通道。 | 消息队列产品 | 7.3.3 |
| 动态事实关联 | 动态事实关联机制 | 通过摄取、语义映射和关系构建把多源数据持续转成可查询语义事实网络的机制。 | 一次性数据导入 | 7.4.1 |
| 动态 Action 关联 | 动态行动关联 | 把决策结果转为受协议、参数、安全校验和反馈约束的可执行数字动作机制。 | 自由文本建议 | 7.4.2 |
| 本体即服务 | Ontology as a Service | 通过标准接口按意图提供可版本化、可授权、可组合本体片段的运行时服务理念。 | 静态本体文件 | 7.4.3 |
| 语义中间件 | 统一语义中间件 | 在平台模块之间统一解析、转换、传递和查询本体知识的集成枢纽。 | 通用 API 网关 | 7.5.5 |
| 穿刺式验证 | 快速穿刺验证 | 以轻量本体、极简 Agent、真实小样本和量化结果快速检验技术链路可行性的作者策略。 | 规模化生产验收 | 8.3.1 |
| 1+4 组织协同 | 总体组加四专业小队 | 总体组统筹本体认知、数据感知、Agent 决策和行动执行四类专业小队的作者组织模式。 | 固定组织架构标准 | 8.3.2 |
| AI 转译 | 知识资产 AI 转译 | 由 AI 将半结构化业务知识初步转换为机器可读本体，再经专家校验和数据连接的过程。 | 自动认证知识 | 8.3.3 |
| 多 Agent PDCA | 多场景 PDCA 自闭环 | 由统筹 Agent 与环节 Agent 按计划、执行、检查、处理协作运行的闭环模式。 | 单 Agent 工作流 | 8.2.6 |
