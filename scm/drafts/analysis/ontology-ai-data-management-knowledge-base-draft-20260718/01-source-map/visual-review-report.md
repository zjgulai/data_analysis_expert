# 《本体驱动的 AI 数据管理》M1 页面视觉复核报告

## 复核方法

- 使用 `pdftoppm` 将指定 PDF 物理页渲染为临时 PNG。
- 人工检查页面类型、图题/表题、文字清晰度与文本层异常原因。
- 临时 PNG 不进入知识库目录，不作为可分发制品保存。

## 发现与处理

1. 文本层中存在“图 3-5 展示了”“图 5-3）以”“图 6-8 所示为”“表 7-2 对比了”等正文引用，首轮规则将其误识别为图表标题。
2. 生成器已增加正文引用过滤规则，保留真正的图题/表题记录。
3. 表 5-27 的编号与标题边界在视觉上存在潜在排版歧义，但当前制品按印刷可见标签原样记录，并留待后续内容复核。

## M1 边界

- 本次视觉复核用于验证抽取与定位，不对书中观点进行真实性背书。
- 未保存整页图像，未调用工作台 provider，未写入 SQLite。
