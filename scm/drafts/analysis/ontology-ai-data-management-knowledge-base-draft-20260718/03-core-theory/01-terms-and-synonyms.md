# 核心理论术语与同义词表

所有词条均为来源派生候选；`aliases` 只用于检索，不表示在所有上下文中完全等价。`not_equivalent_to` 用于防止概念误并。

| 首选词 | 检索别名 | 来源内定义 | 不等同于 | 来源小节 |
|---|---|---|---|---|
| 本体 | Ontology | 作者所述的形式化、结构化业务意义框架，用于显式组织概念、关系、规则和行动，使知识可被人理解并被机器计算。 | 知识图谱；实体模型 | 4.1.1 |
| 业务本体 | 企业业务本体 | 围绕具体业务任务或决策组织事实、事理与行动，并供 AI Agent 理解、推理和执行的本体模型。 | AI 业务数据 | 4.1.2、5.1.3 |
| 事实 | 业务事实 | 对业务对象、关系、事件和当前状态的可追溯描述，回答发生了什么或当前是什么。 | 事理；推理结果 | 4.1.2、5.3.1 |
| 事理 | 业务事理；事理逻辑 | 对业务规则、原因、约束、流程和决策机制的表达，回答为什么以及应如何运作。 | 事实；行动 | 4.1.2、5.3.2 |
| 行动 | 业务行动；Action | 由目标、前置条件、输入输出、执行效果和反馈约束的可实施业务动作。 | 自然语言建议 | 4.1.2、5.4.5、5.5.3 |
| 语义互联 | 语义互操作 | 不同系统、组织或数据来源在交换数据时保持概念含义和解释一致的能力。 | 物理连接；语义推理 | 4.1.3 |
| 语义推理 | 本体语义推理 | 基于形式化概念、属性约束和逻辑规则推导结论，并为 AI 提供业务常识与行为边界的能力。 | 向量相似检索；语义互联 | 4.1.3 |
| 符号主义 | Symbolic AI | 以符号、概念和规则表达知识并进行可解释确定性推理的智能路线。 | 联结主义 | 4.1.4 |
| 联结主义 | Connectionism | 依靠神经网络和数据学习统计模式，擅长模式识别、概率推理和泛化的智能路线。 | 符号主义 | 4.1.4 |
| 混合智能 | 符号主义+联结主义 | 以形式化规则和业务语义增强神经网络概率推理，使确定性边界与泛化能力协同的架构方向。 | 纯规则系统；纯概率模型 | 4.1.4、4.2.1 |
| 本体语义层 | 统一语义层 | 位于业务、信息、应用和技术架构之间，将业务共识转为机器可理解模型并提供统一语义调用的架构层。 | API 网关；数据仓库 | 4.4.1 |
| 实体建模 | ERD；实体关系建模 | 围绕实体、属性和值记录业务事实和结构，主要回答业务中有什么。 | 本体建模 | 4.4.2 |
| 知识图谱 | Knowledge Graph；KG | 以实体及关系承载实例化知识的数据结构；在作者框架中，本体提供其语义骨架和推理规则。 | 本体；本体库 | 4.4.3 |
| 本体库 | Ontology Repository | 存储形式化概念、关系、规则和行动语义，面向 AI Agent 提供可推理业务逻辑的知识基础设施。 | 数据湖；文档知识库 | 4.4.4 |
| AI 数据资产 | 面向 AI 的数据资产 | 面向大模型训练与 AI Agent 推理组织的数据集、事实数据、事理模型和推理结果等可治理资产。 | 训练数据集 | 5.1.3 |
| AI 业务数据 | — | 以 AI 任务或决策为管理锚点，但其事理尚未完成本体建模，可能以 Prompt 或文本方式表达的业务数据集合。 | AI 业务本体 | 5.1.3 |
| AI 业务本体 | — | 以具体 AI 任务或决策为管理锚点，已经把相关事理本体化并贯通事实、事理与行动的业务模型。 | AI 业务数据 | 5.1.3 |
| AI 数据集 | AI Dataset | 用于模型训练、验证、测试或知识表征，并作为责任、共享、风险和生命周期管理基本单元的数据集合。 | 全部 AI 数据资产 | 5.2.1、5.2.2 |
| 事实数据 | 推理态事实数据 | 与推理任务直接相关的结构化、非结构化或关系数据，用于还原业务当前状态并支撑精准判断。 | 事理模型；推理结果数据 | 5.3.1 |
| 事理模型 | 业务事理模型 | 将企业规则、决策逻辑、流程、权限和目标转为 AI 可理解结构化语义的推理逻辑载体。 | 事实数据；Prompt 文本 | 5.3.2 |
| 本体语义模型 | — | 事理模型的一种具象化管理单元，基于形式化语义规范表达特定 AI 推理任务的业务逻辑。 | 所有事理表达形式 | 5.3.2 |
| 推理结果数据 | AI 推理结果数据 | 每次 AI 推理任务产生的结果与过程日志，作为可关联任务、来源版本和评估的业务痕迹。 | 事实数据 | 5.3.3 |
| 数据 Owner | 数据所有者 | 作者所述的业务数据端到端责任角色，负责数据体系、质量、底座服务、安全授权与定密等。 | AI 数据集责任人 | 5.2.3 |
| AI 数据集责任人 | 数据集提供方责任人 | 负责 AI 数据集采集、注册、质量、发布、更新、许可、安全和生命周期的供给责任角色。 | 数据 Owner；AI 数据集使用责任人 | 5.2.3 |
| AI 数据集使用责任人 | 数据集消费方责任人 | 对 AI 数据集在许可范围内的安全、隐私、合规、质量和使用结束后的处置承担责任的消费角色。 | AI 数据集责任人 | 5.2.3 |
| RDF | Resource Description Framework | 作者映射为以主语、谓语、宾语三元组描述业务资源和事实关联的基础语义标准。 | OWL；SPARQL | 5.4.1 |
| OWL | Web Ontology Language | 作者映射为表达类层级、属性约束、等价和基数等逻辑语义的本体语言。 | RDF；SWRL | 5.4.2 |
| SKOS | Simple Knowledge Organization System | 作者映射为统一术语定义、分类和关联，建立受控词表与语义共识的标准。 | OWL | 5.4.3 |
| SWRL | Semantic Web Rule Language | 作者映射为以如果—那么规则组合事实与约束并推导结论的规则语言。 | OWL | 5.4.4 |
| OWL-S | Web Ontology Language for Services | 作者映射为用输入、输出、前置条件和效果描述服务、流程活动与行动原语的语义规范。 | BPMN；OWL | 5.4.5 |
| ODRL | Open Digital Rights Language | 作者映射为表达许可、禁止、义务、资产和使用约束的权限与策略语言。 | 身份认证系统 | 5.4.6 |
| SPARQL | SPARQL Protocol and RDF Query Language | 作者映射为查询和操作 RDF 图数据、支持 Agent 按意图取用本体数据的接口语言。 | RDF | 5.4.7 |
| 目标与评估 | 目标评估规范 | 7+1 中用于明确 AI 任务、业务效果、质控标准和所依赖事理的结构化维度。 | 单一模型指标 | 5.4.8 |
