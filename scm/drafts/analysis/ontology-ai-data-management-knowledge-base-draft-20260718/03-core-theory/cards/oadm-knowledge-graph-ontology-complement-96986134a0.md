# 知识图谱与本体的骨架—实例关系

## 核心结论

作者把本体视为定义类、属性和规则的语义骨架，把知识图谱视为承载实例与关系的实际数据，二者形成逻辑定义与数据落地闭环。

## 关键要素

- 基础知识图谱偏向关联查询和可视化。
- 语义增强型增加标签或局部规则。
- 本体语义型通过公理和规则支撑机器推理。

## 适用场景

- 选择知识图谱能力层级
- 区分面向人检索与面向 Agent 推理

## 不适用边界

- 三类能力层次是作者分类，不是强制行业分级。
- 使用本体标准不自动保证推理质量。
