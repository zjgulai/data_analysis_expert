# 从语义互联到语义推理

## 核心结论

作者区分两层本体价值：语义互联让跨系统数据含义一致，语义推理把概念、规则和约束转为 AI 可计算的业务常识与行动边界。

## 关键要素

- 语义互联解决跨来源、跨系统和跨机构的含义对齐。
- 语义推理提供可计算概念、逻辑规则和行为约束。
- 价值需通过真实业务行动而非模型规模体现。

## 适用场景

- 设计跨系统语义层
- 从知识图谱检索升级到 Agent 决策

## 不适用边界

- 书中 FIBO、EDS 等案例属于作者案例，未在项目侧独立核验。
- 互联能力不等于推理能力，二者须分层验收。
