# 企业架构中的本体语义层

## 核心结论

作者把本体语义层定义为业务架构与信息、应用、技术架构之间的机器可理解桥梁，向上承接业务共识，向下统一调用数据、服务和资源。

## 关键要素

- 存量架构和制度转成机器可读语义。
- 增量场景通过同一业务共识进行逻辑推演。
- 语义接口连接目标、数据、应用与基础设施。

## 适用场景

- 在企业架构中定位本体能力
- 规划存量语义化与增量 AI 场景

## 不适用边界

- 语义层不替代现有 4A 架构治理。
- 统一语义接口仍需具体 API、数据契约和权限实现。
