# 本体模型与大模型的三重连接

## 核心结论

作者以人机协同连接、模型连接和内容连接说明本体如何把人的战略规则、业务逻辑骨架与 Token 语义带入大模型推理。

## 关键要素

- 人机协同连接明确人定规则、AI 感知推理执行的分工。
- 模型连接以本体为业务逻辑骨架。
- 内容连接让明文规则与向量化经验协同。

## 适用场景

- 设计本体增强 LLM 的集成边界
- 审查规则、模型和人员是否形成闭环

## 不适用边界

- 三重连接是作者概念框架，不能替代接口、权限和运行时设计。
- 连接本体不等于模型已经遵循本体。
