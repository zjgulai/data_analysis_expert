# W3C 语义技术栈的作者映射

## 核心结论

作者将 RDF、OWL、SKOS、SWRL、OWL-S、ODRL 和 SPARQL 组合为覆盖资源、术语、约束、规则、行动、权限与查询的语义技术栈。

## 关键要素

- RDF 负责资源与三元组描述。
- OWL、SKOS 与 SWRL 负责概念、术语和规则。
- OWL-S、ODRL 与 SPARQL 连接行动、权限和数据操作。

## 适用场景

- 制定企业语义规范候选技术图谱
- 映射 7+1 语义维度

## 不适用边界

- 本卡记录书中映射，不等同于 W3C 官方组合架构。
- 各标准的当前状态和适用范围需查官方文档后才能工程采用。
