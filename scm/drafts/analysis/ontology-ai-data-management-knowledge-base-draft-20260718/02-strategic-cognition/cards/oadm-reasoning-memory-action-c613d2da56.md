# 大模型能力跃升的推理—记忆—行动三要素

## 核心结论

作者以推理、记忆和行动概括大模型能力跃升：推理用于分解和判断，记忆用于保持和调用上下文，行动用于借助工具影响外部环境。

## 关键要素

- 推理：围绕目标形成判断和步骤。
- 记忆：保留上下文、经验或可检索知识。
- 行动：把语言输出延伸为工具调用和任务执行。

## 适用场景

- 划分企业 AI 能力建设维度
- 审查 Agent 是否只有生成能力而缺少记忆或执行闭环

## 不适用边界

- 三要素是作者的归纳框架，不代表已验证的统一行业成熟度模型。
- 具备工具调用接口不等于已经具备可信行动能力。
